# ConsGHost

[English](../../README.md) · [简体中文](README.zh-CN.md) · **Русский** · [Español](README.es.md) · [Français](README.fr.md)

ConsGHost (CGH) загружает моды на C# и C++ в 64-разрядную версию Garry's Mod для Windows. Мод может работать в процессе игры или в отдельном процессе. Вместе с модом можно поставлять обычные дополнения Garry's Mod в виде папок или файлов `.gma`.

## Установка и запуск

1. Установите [.NET 10 Desktop Runtime для Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) и войдите в Steam. Нужны Windows 10 или 11 и установленная Garry's Mod с файлом `gmod_win64.exe`.
2. Скачайте `CGH-<версия>-win-x64.zip` со [страницы релизов](https://github.com/LytharaLab/ConsGHost/releases). Распакуйте весь архив в папку, доступную для записи, сохранив структуру каталогов.
3. Запустите `ConsGHost.Host.exe`. Откройте последний пункт бокового меню, **Настройки**, и укажите папку с `gmod_win64.exe`. В Steam её можно открыть через меню управления игрой, выбрав просмотр локальных файлов.
4. Проверьте список включённых модов и запустите игру из CGH. В архив входят BridgeDemo и Observer. Они показывают вызовы между C# и C++ и обмен сообщениями между процессами.

По умолчанию CGH запускает игру с параметром `-insecure`, предназначенным для локальной разработки. Используйте локальные сеансы и загружайте моды и дополнительные DLL из доверенных источников. Отдельный процесс изолирует сбой мода, но работает с правами вашей учётной записи Windows.

По умолчанию CGH использует язык интерфейса Windows. Если этот язык отсутствует, CGH открывается на английском. В разделе **Настройки → Язык интерфейса** можно выбрать английский, упрощённый китайский, русский, испанский или французский. Выбор применяется сразу и сохраняется для следующего запуска.

## Установка модов

Поместите каждый мод в отдельную папку внутри `Mods/` рядом с `ConsGHost.Host.exe`. Моду нужен файл `cghm_metadata.json`. Также можно добавить `Managed/`, `Native/`, `Resources/`, `Addons/` и шаблон `config.default.json`. При первом обнаружении мода с шаблоном CGH создаёт `config.json`. Формат метаданных и работу с SDK описывает [руководство для разработчиков модов](../mod-development.md).

CGH хранит настройки в `cgh_settings.json`, журналы сеансов в `Sessions/`, а данные модов в `Data/<mod-id>/`. При обновлении распакуйте новую версию в отдельную папку и перенесите нужные моды и данные. Сохраните конфигурации модов и проверьте настройки перед запуском.

## Сборка из исходного кода

Понадобятся .NET 10 SDK, Visual Studio 2022 Build Tools с компонентами для разработки классических приложений на C++, Windows SDK и CMake 3.24 или новее. В PowerShell перейдите в корень репозитория и выполните команды ниже.

```powershell
./build.ps1
./artifacts/CGH/ConsGHost.Host.exe
```

`./test.ps1` запускает проверки нативного кода, интеграции и интерфейса. `./package.ps1` создаёт ZIP для Windows x64 и файл контрольной суммы SHA-256 в `artifacts/`. См. [руководство по проверке](../verification.md).
